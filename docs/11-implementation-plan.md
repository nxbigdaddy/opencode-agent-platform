## 1. 项目概述

### 1.1 项目目标

将 OpenCode CLI 转化为生产级远程 Agent 引擎，构建支撑多用户、多会话、多工具的 AI 对话服务平台。

### 1.2 项目范围

**包含**：
- Web 对话界面
- 管理后台
- 多租户会话管理
- Agent 配置与路由
- MCP 工具生态集成
- 企业微信/钉钉机器人
- 审计与计费系统

**不包含**：
- LLM 模型训练
- 移动端原生 App（使用 PWA）

### 1.3 项目周期

**总工期**：10 周  
**开始日期**：2026-04-21  
**计划完成日期**：2026-06-30

## 3. Phase 1：基础验证（第 1-2 周）

### 3.1 目标

验证 OpenCode 远程服务化可行性，搭建最小可运行原型。

### 3.2 任务分解

#### Week 1

| 任务 | 负责人 | 工时 | 产出 |
|------|--------|------|------|
| **环境搭建** | DevOps | 2d | 开发环境、CI/CD 流水线 |
| **OpenCode 部署** | Backend | 2d | `opencode serve` 稳定运行 |
| **最小 Gateway** | Backend | 3d | FastAPI SSE 透传接口 |
| **前端原型** | Frontend | 3d | React 单页面聊天原型 |

#### Week 2

| 任务 | 负责人 | 工时 | 产出 |
|------|--------|------|------|
| **工作区隔离验证** | Backend | 2d | 多目录测试通过 |
| **基础认证** | Backend | 2d | JWT 登录/注册 |
| **消息持久化** | Backend | 2d | PostgreSQL 消息表 |
| **原型集成测试** | QA | 2d | 测试报告 |

### 3.3 技术验证点

| 验证项 | 方法 | 通过标准 |
|--------|------|----------|
| OpenCode SSE 接口 | curl 测试 | 本地可调用，流式返回正常 |
| Gateway 透传 | 前端连接测试 | SSE 事件正确转发 |
| 工作区隔离 | 文件系统测试 | 会话 A 无法访问会话 B 文件 |
| 并发连接 | 多客户端测试 | 同时 10 个连接正常 |

### 3.4 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| OpenCode SSE 不稳定 | 高 | 准备降级方案（轮询） |
| 工作区隔离实现复杂 | 中 | 先用 Docker 容器隔离 |

## 8. 风险管理

### 8.1 风险登记册

| 风险 ID | 风险描述 | 可能性 | 影响 | 风险等级 | 应对策略 | 负责人 |
|---------|----------|--------|------|----------|----------|--------|
| R1 | OpenCode API 变更 | 中 | 高 | 高 | 封装抽象层，关注官方 Changelog | 架构师 |
| R2 | LLM API 响应慢 | 高 | 中 | 中 | 超时控制、流式返回、降级策略 | 后端 |
| R3 | Token 费用暴涨 | 中 | 高 | 高 | 用量配额、实时监控、告警 | PM |
| R4 | MCP 权限逃逸 | 低 | 高 | 中 | 沙箱化、白名单、审计 | 安全 |
| R5 | 并发性能不足 | 中 | 中 | 中 | 压测、优化、扩容 | DevOps |
| R6 | 团队成员离职 | 低 | 中 | 低 | 文档完善、知识共享 | PM |
| R7 | 第三方服务故障 | 中 | 中 | 中 | 降级策略、多供应商 | 后端 |
| R8 | 安全漏洞 | 低 | 高 | 中 | 安全扫描、渗透测试 | 安全 |

### 8.2 风险应对措施

#### R1：OpenCode API 变更

- **预防**：封装 OpenCode 客户端，隔离底层变化
- **监测**：订阅官方 Release Notes
- **应对**：预留 1 周缓冲时间处理 API 变更

#### R3：Token 费用暴涨

- **预防**：用户级用量配额
- **监测**：实时 Token 消耗监控
- **应对**：超限时自动降速或暂停服务

#### R4：MCP 权限逃逸

- **预防**：Firejail 沙箱、命令白名单
- **监测**：审计日志、异常行为检测
- **应对**：自动隔离异常 MCP 进程
