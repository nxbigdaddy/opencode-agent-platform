## 2. 总体描述

### 2.1 系统视角

本平台作为企业内部的 AI 助手基础设施，为员工提供基于 OpenCode 的编程辅助、数据分析、文档编写等服务。

### 2.2 用户类别

| 用户角色 | 描述 | 数量预估 |
|----------|------|----------|
| **普通用户** | 使用平台完成日常工作的员工 | 500+ |
| **管理员** | 管理系统配置、用户、审计 | 5-10 |
| **运维人员** | 监控系统、处理故障 | 2-5 |
| **API 消费者** | 通过 API 集成第三方系统 | 10+ |

### 2.3 运行环境

- **服务器**：Ubuntu 22.04/24.04 LTS
- **容器**：Docker 24.x + Docker Compose
- **浏览器**：Chrome 120+, Firefox 120+, Safari 17+
- **移动端**：iOS Safari, Android Chrome（PWA）

## 3. 功能需求

### 3.1 用户认证模块

#### FR-AUTH-001 用户注册

**描述**：新用户通过邀请码或管理员创建账号

**前置条件**：
- 系统已配置邮件服务（可选）
- 管理员已生成邀请码

**基本流程**：
1. 用户访问注册页面
2. 输入用户名、密码、邀请码
3. 系统验证邀请码有效性
4. 系统创建用户账号
5. 返回登录页面

**验收标准**：
- [ ] 用户名唯一，长度 3-50 字符
- [ ] 密码复杂度：至少 8 位，包含大小写字母和数字
- [ ] 邀请码一次性使用，过期时间 7 天
- [ ] 注册成功返回 201，失败返回具体错误信息

#### FR-AUTH-002 用户登录

**描述**：已注册用户通过用户名密码登录

**基本流程**：
1. 用户输入用户名和密码
2. 系统验证凭据
3. 生成 JWT Token（Access + Refresh）
4. 返回 Token 和用户信息

**验收标准**：
- [ ] Access Token 有效期 15 分钟
- [ ] Refresh Token 有效期 7 天
- [ ] 支持"记住我"功能（延长 Refresh Token 至 30 天）
- [ ] 登录失败 5 次锁定账号 30 分钟

#### FR-AUTH-003 OAuth 登录

**描述**：支持通过企业微信、钉钉、GitHub OAuth 登录

**验收标准**：
- [ ] 支持企业微信 OAuth 2.0
- [ ] 支持钉钉扫码登录
- [ ] 支持 GitHub OAuth
- [ ] 首次 OAuth 登录自动创建账号

#### FR-AUTH-004 Token 刷新

**描述**：Access Token 过期后使用 Refresh Token 获取新的 Token

**验收标准**：
- [ ] Refresh Token 一次性使用，使用后失效
- [ ] 新的 Refresh Token 随 Access Token 一起返回
- [ ] Refresh Token 过期需重新登录

#### FR-AUTH-005 登出

**描述**：用户主动登出系统

**验收标准**：
- [ ] Access Token 加入 Redis 黑名单
- [ ] Refresh Token 失效
- [ ] 清除客户端存储的 Token

### 3.2 会话管理模块

#### FR-SESSION-001 创建会话

**描述**：用户创建新的 AI 对话会话

**基本流程**：
1. 用户点击"新建会话"
2. 系统创建会话记录
3. 系统初始化工作区目录
4. 系统创建 OpenCode 会话
5. 返回会话信息

**验收标准**：
- [ ] 会话标题默认"新会话"，支持 AI 自动生成
- [ ] 会话关联默认 Agent（Build）
- [ ] 工作区目录隔离：/workspaces/{user_id}/{session_id}/
- [ ] 创建时间记录在案

#### FR-SESSION-002 会话列表

**描述**：用户查看自己的所有会话

**验收标准**：
- [ ] 分页展示，每页 20 条
- [ ] 支持按时间排序（最新/最早）
- [ ] 支持搜索（标题、内容关键词）
- [ ] 显示最后消息时间和消息数

#### FR-SESSION-003 切换会话

**描述**：用户在多个会话间切换

**验收标准**：
- [ ] 切换时保留当前会话状态
- [ ] 加载目标会话历史消息（分页）
- [ ] 会话未读消息标记清除
- [ ] 切换响应时间 < 500ms

#### FR-SESSION-004 删除会话

**描述**：用户删除不需要的会话

**验收标准**：
- [ ] 软删除（标记 deleted，保留数据）
- [ ] 管理员可恢复已删除会话
- [ ] 删除后释放工作区存储（延迟任务）
- [ ] 确认弹窗防止误操作

#### FR-SESSION-005 会话归档

**描述**：用户将会话归档，不再显示在活跃列表

**验收标准**：
- [ ] 归档会话移至"归档"标签
- [ ] 支持取消归档
- [ ] 归档会话可查看但不可编辑

### 3.3 对话功能模块

#### FR-CHAT-001 发送消息

**描述**：用户向 AI 发送文本消息

**基本流程**：
1. 用户输入消息内容
2. 前端通过 SSE 发送请求
3. 网关转发至 OpenCode Server
4. OpenCode 处理并流式返回
5. 前端实时展示响应

**验收标准**：
- [ ] 支持多行文本（Shift+Enter 换行）
- [ ] 消息长度限制：用户 4000 tokens，系统 8000 tokens
- [ ] 支持 Markdown 格式输入
- [ ] 发送后显示"思考中"状态

#### FR-CHAT-002 流式响应

**描述**：AI 响应以流式方式实时展示

**验收标准**：
- [ ] 首字返回时间 < 3s
- [ ] 支持打字机效果（逐字显示）
- [ ] 支持代码块实时高亮
- [ ] 支持 Markdown 实时渲染
- [ ] 显示 Token 消耗统计

#### FR-CHAT-003 工具调用展示

**描述**：AI 调用工具时展示执行过程

**验收标准**：
- [ ] 展示工具名称和参数（可展开）
- [ ] 展示工具执行结果
- [ ] 支持重试失败的工具调用
- [ ] 工具调用耗时显示

#### FR-CHAT-004 文件上传

**描述**：用户上传文件作为消息附件

**验收标准**：
- [ ] 支持文件类型：txt, md, py, js, ts, json, yaml, csv, pdf, png, jpg
- [ ] 单文件大小限制：10MB
- [ ] 单次最多上传 5 个文件
- [ ] 上传进度显示
- [ ] 文件内容自动提取并作为上下文

#### FR-CHAT-005 代码操作

**描述**：AI 生成的代码支持一键操作

**验收标准**：
- [ ] 支持复制代码块
- [ ] 支持插入到工作区文件
- [ ] 支持创建新文件
- [ ] 代码 diff 预览

#### FR-CHAT-006 消息历史

**描述**：查看和加载历史消息

**验收标准**：
- [ ] 分页加载，每页 20 条
- [ ] 滚动到顶部自动加载更早消息
- [ ] 支持消息搜索
- [ ] 支持跳转到指定消息

| 编号 | 需求 | 实现方式 |
|------|------|----------|
